# 🎂 Birthday Surprise Website

A beautiful, interactive birthday greeting website with animations, messages, and confetti!

## Features ✨

- 🎁 Beautiful welcome screen
- 💌 Personalized birthday message
- 📸 Memory gallery section
- 💗 Interactive clickable reasons/messages
- 🎉 Confetti animation
- 📱 Fully responsive design
- ✨ Smooth animations and transitions

## How to Use

1. Open `index.html` in your browser
2. Click "Open Your Surprise" button
3. Explore the different sections
4. Click on the emoji boxes to reveal special messages
5. Click "Make a Wish" to create confetti!

## Customization

### Change Messages
Edit the `messages` array in `script.js`:
```javascript
const messages = [
    "Your custom message here 💌",
    "Another message 🌸",
    "One more message ⭐"
];
```

### Change Colors
Edit the CSS variables in `style.css`:
```css
:root {
    --primary: #ff6b9d;
    --secondary: #c44569;
    --light: #ffd6e8;
}
```

### Add Photos
Replace the photo placeholders in `index.html` with your own images.

## Files

- `index.html` - Main HTML structure
- `style.css` - Styling and animations
- `script.js` - Interactive functionality
